The working theme: the ledger. For tools used all day - a cool gray whisper in the neutral, color eased down so status reads without shouting, compact spacing and leading (visibly tighter than the base, so the registry's two entries read as two choices), one sans family, a flatter type scale, and restrained corners and depth. Plain on purpose: no decoration, no clipped gamut, the default accent.

Dual-scheme and semantic-tier - it moves levers only, so the palette letters keep their hues and it sits in the registry beside the base theme.
