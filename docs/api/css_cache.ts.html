Cache infrastructure for incremental CSS class extraction.

Provides per-file caching with content hash validation to avoid re-extracting classes from unchanged files.

to_cache_version

css_cache.ts view source

to_cache_version(versions?: Record<string, string>): string

Computes the cache version every entry is written with and checked against: the versions of fuz_css and the parsers its extractor runs, so an upgrade of any of them invalidates the cache with no manual bump. In a checkout of fuz_css itself the version doesn't move between commits, so clear .fuz/cache/css and each example's own .fuz directory (or set cache_salt) after changing what extraction produces.

import {to_cache_version} from '@fuzdev/fuz_css/css_cache.js';

to_extraction_cache_key(acorn_plugins: (AcornPlugin)[] | undefined, cache_salt: string | undefined): string | null

Computes the part of the cache key that comes from configuration rather than file content: a fingerprint of the configured acorn plugins (their source text) and the consumer's cache_salt, or null when neither is set. A plugin's options live in its closure, where the source text can't see them, so a consumer who changes only a plugin's options bumps cache_salt.

import {to_extraction_cache_key} from '@fuzdev/fuz_css/css_cache.js';
