fuz_css

CSS with more utility 🪴

fuz_css is a semantic-first CSS framework and design system. Semantic HTML looks finished with zero classes: headings, links, buttons, forms, tables, and callouts come styled, and block elements space themselves. Themes are a handful of knobs, not a stylesheet: hues, intents, lightness curves, and scales re-derive every color and size in plain CSS, and the contrast, gamut, and ramp-order checks the shipped themes pass are an API for checking your own. See the themes and try the editor.

The Vite plugin generates one stylesheet with the theme variables, base styles, and utility classes your code uses, for Svelte, React, Preact, Solid, and plain HTML. Without a build step, link the package's two plain stylesheets. For companion Svelte components see fuz_ui.

More at the docs and repo.

⚠️ fuz_css is in early alpha with breaking changes ahead. Your input and feedback is appreciated in the GitHub issues for bugs and discussions for everything else.
